# WealthQuant

WealthQuant is a quantitative trading platform that I'm building to research, analyze, and test market strategies using Python, FastAPI, React, and PostgreSQL.

The goal of this project is to combine market data, options analytics, technical indicators, machine learning, and backtesting into a single platform that helps evaluate trading ideas with a data-driven approach.

## Features

- Market data collection and processing
- Options chain analysis
- Technical indicators
- Portfolio tracking
- Backtesting engine
- Explainable AI for model decisions
- FastAPI backend
- React dashboard
- PostgreSQL database

## Tech Stack

- Python
- FastAPI
- React
- PostgreSQL
- Pandas
- NumPy
- SQLAlchemy

## Status

The project is under active development, and new features are added regularly. Some modules are still experimental and may change as the platform evolves.

## Running the Project

Backend

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Frontend

```bash
cd frontend
npm install
npm start
```

## Why I Built This

I wanted a platform where I could experiment with quantitative trading strategies, validate ideas through backtesting, and bring multiple research tools into one place instead of relying on separate applications.
