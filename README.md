# WealthQuant

An AI-powered market intelligence and quantitative analytics platform for the Indian stock market, built with FastAPI, React, PostgreSQL, and machine learning.

WealthQuant combines live market data, options analytics, statistical models, explainable AI, and quantitative research into a unified platform for data-driven market analysis and decision support.

> **Note:** WealthQuant is a research and analytics platform. It is not an automated trading system.

---

## Key Features

- Live market intelligence
- Options chain analytics
- Multi-factor signal generation
- AI-powered probability forecasting
- Market regime detection
- Explainable AI
- Institutional order flow analysis
- Quantitative research
